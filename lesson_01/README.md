## How to use these

**Paste the contents, do not attach the file.** You will see more of what is happening,
and it puts the material above your instruction, which is the ordering that works.

**Use your own real work wherever you can.** Every exercise in the lab guide is written so
a made-up example will technically work and teach you much less. These files exist so you
are never blocked, not because they are better than your own data.

## The order

**`try_it_yourself.md` first.** It replays what you watched, so the session sticks.

**`lab_guide.md` second.** Same ideas on your own work, which is where the habit forms.

**If you only do one thing:** build a real Project for work that comes back every week.
It is number 3 on both lists, and it is the one that changes a working week rather than a
single afternoon.
