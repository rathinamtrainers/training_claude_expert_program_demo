# A hard reasoning puzzle

Paste the block below into Claude, unchanged. Try it on the cheapest model first, then on
the most capable one, and compare.

There is exactly one valid schedule. Work it out yourself before you decide whether the
answer you got is right.

```
Schedule 5 one-hour interviews in a single day, between 09:00 and 16:00, with a hard
one-hour lunch break from 13:00 to 14:00 when nothing can be scheduled.

The candidates are Asha, Bala, Chitra, Dev and Eshan.

Rules:
- Asha is only available before noon.
- Bala must be interviewed immediately after Asha, with no gap.
- Chitra cannot be the first interview of the day.
- Dev must be interviewed after lunch.
- Eshan must be the last interview of the day.
- Exactly one hour of the day is left empty, and it is the hour immediately before lunch.

Give the schedule as a list of times and names. Then state which rule forced each
placement.
```
